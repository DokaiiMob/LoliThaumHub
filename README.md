## ⚙️ Архитектура и Функционал (Техномагия)

Инструмент оперирует аспектами как **узлами (нодами)** ненаправленного графа, а рецепты их создания представлены как **ребра (линки)**.

*   **Трассировка Пути (Алгоритм BFS):** Встроенный алгоритм поиска в ширину (Breadth-First Search) вычисляет кратчайший трансмутационный маршрут между двумя любыми аспектами. Сеть автоматически проложит пульсирующий вектор через все промежуточные компоненты.
*   **Рекурсивная Иллюминация:** Наведение на любой составной аспект запускает рекурсивный обход дерева зависимостей, подсвечивая все базовые аспекты (пра-родители), необходимые для его синтеза.
*   **Динамическая Топология:** Отрисовка эфирной сети в реальном времени. Переключение между строгой матричной координатной сеткой и спиралью Архимеда с настраиваемым коэффициентом плотности (масштабом).
*   **Энергонезависимая Память:** Сохранение текущего расположения узлов и статуса их изучения в бинарно-текстовом формате (JSON конфиг).

## 📜 Манускрипт Управления (Как этим пользоваться)

Интерфейс спроектирован для интуитивного, но глубокого взаимодействия. Рабочее пространство представляет собой бесконечный canvas.

### 🖱️ Паттерны манипуляции:
| Действие | Триггер | Результат |
| :--- | :--- | :--- |
| **Кинетический захват** | <kbd>ЛКМ</kbd> (Зажать и тянуть) | Перемещение узла аспекта по рабочему пространству или панорамирование самой камеры (если тянуть за пустоту). |
| **Оптический зум** | <kbd>Колесо мыши</kbd> | Масштабирование эфирной проекции (приближение/отдаление). |
| **Маркировка нейросети** | <kbd>ПКМ</kbd> по узлу | Пометить аспект как "Изученный" (зеленый контур). Влияет только на вашу визуальную ориентацию. |
| **Векторный поиск (Pathfinding)** | <kbd>Alt</kbd> + <kbd>ЛКМ</kbd> | Выберите два любых узла с зажатым Alt. Система запустит алгоритм BFS и проложит анимированный маршрут крафта между ними. Выбор третьего узла сбросит первую точку. |

### 🎛️ Элементы Контрольной Панели:
*   **[Строка Поиска]** — Лексический фильтр. Введите латинское название (например, `Victus`), и интерфейс погрузит все нерелевантные ноды во тьму, оставив только искомый элемент.
*   **[Ползунок "Масштаб сетки"]** — Изменяет математический шаг (дистанцию) между узлами при автоматической генерации раскладок. Установите значение и нажмите одну из кнопок топологии.
*   <kbd>Сетка</kbd> / <kbd>Спираль</kbd> — Принудительная реорганизация всех узлов в выбранную геометрическую фигуру с учетом заданного масштаба.
*   <kbd>🏠</kbd> **(Сброс камеры)** — Возвращает координаты видоискателя в нулевую точку `(x:0, y:0)` и восстанавливает дефолтный масштаб.
*   <kbd>💾</kbd> **(Экспорт конфига)** — Дамп текущей памяти браузера. Скачивает файл `thaum_v2.3.json` с вашим расположением узлов и изученными метками. *(Для загрузки обратно просто перетащите файл в окно браузера)*.
*   <kbd>Сброс</kbd> — Полное стирание прогресса. Снимает метки "Изучено" со всех аспектов графа.
